# رايح جاي (Rayeh Jay) 🚛

منصة النقل والشحن التشاركي في الجزائر: تربط أصحاب الحمولات بالناقلين العائدين فارغين على خط سيرهم، لحل مشكلة «الرحلة الفارغة».

## المزايا
- البحث عن رحلات العودة حسب الولاية والمسار وفئة المركبة (C1, C2, E, Porte-char, B)
- اقتراح ذكي لفئة الشاحنة المناسبة حسب الوزن ونوع البضاعة
- خريطة تفاعلية (Leaflet) للمسارات
- لوحة للناقل: نشر رحلة عودة، الإبلاغ عن تأخير، إنهاء الرحلة
- توثيق بيانات الناقل، وطلبات الاتصال المباشر
- واجهة عربية RTL مع دعم التعدد اللغوي (`src/locales`)

## التقنيات
React 19 · TypeScript · Vite · Tailwind CSS 4 · Leaflet · lucide-react

## التشغيل محلياً
```bash
npm install
npm run dev        # http://localhost:5173
```

## البناء
```bash
npm run build      # الناتج في dist/
npm run preview
```

## GitHub Actions
- `ci.yml`: يعمل تلقائياً عند كل push/PR: تثبيت ← فحص الأنواع ← بناء.
- `deploy-pages.yml`: نشر على GitHub Pages يدوياً من تبويب Actions (فعّل Pages بمصدر «GitHub Actions» من إعدادات المستودع).

## ملاحظات مهمة
- **لا يوجد خادم خلفي حالياً**: البيانات (الرحلات، الطلبات، المستخدم) تُحفظ في `localStorage` للمتصفح عبر `src/services/api.ts` وبيانات تجريبية جاهزة. لإطلاق حقيقي يلزم API وقاعدة بيانات ومصادقة.
- **تطبيق أندرويد**: المشروع تطبيق ويب. لتوليد APK حقيقي استخدم [Capacitor](https://capacitorjs.com) أو غلافاً مشابهاً فوق مخرجات `dist/`.
